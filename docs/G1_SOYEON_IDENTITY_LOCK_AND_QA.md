## 이미지 생성 1회 = 단일 컷 1장
- 한 프레임에는 **한 카메라 시점의 하나의 상황만**. 여러 장면, 그리드, 콜라주, 몽타주, 캐릭터 시트, 그래픽·한국어 레이블, 패널, 말풍선 금지.
- 재크롭·재배치·분할 시트에서 추출한 이미지는 **독립 생성 원본으로 간주하지 않음**.
- `num_images=1`을 명시하고 텍스트 설명에도 "exactly one single uninterrupted photograph, no other panels, only one camera exposure" 포함.
- 승인 얼굴과 비교해 머리, 얼굴형, 눈, 피부, 연령이 달라지면 불합격.
- 별도의 전신 사진은 머리 꼭대기부터 부츠 밑창까지 보여야 한다. 앉아 있거나 무릎 이하가 잘린 사진은 전신으로 인정하지 않는다.
- 장면컷은 기존 승인컷과 **다른 행동·위치·구도**를 보여야 한다. 배경·포즈만 조금 움직인 거의 같은 컷은 재사용으로 판정한다.
- 실제 소방 현장·생존 상황에 적합한 복장/장비로 연출. 과도한 피부 보정·인위적 모델 촬영·게임 CG 느낌 금지.

## 재작업 순서
1. 원본 얼굴 바이너리를 수정 없이 보존하고 외형 잠금 해시 검증.
2. **서서 촬영한 전신 2:3 사진 1장** 독립 생성. 검사 실패 시 납품 목록에 넣지 않는다.
3. 전신 통과 후 `c3e` 방화문 외부 구조 요청, `c4a` 방화문 개방과 대피 지원, `c4b` 복도 방어, `c4c` 동료 회의, `c4d` 철제 지지대 구조, `c4e` 강변 야영 등 **스토리 원문에 등장하는 장면 ID별로 서로 다른 상황 컷**을 독립 생성한다. 다른 출연자가 나오는 장면은 각자 승인 레퍼런스를 함께 사용한다.
4. 매 컷마다 단일사진/얼굴 일치/행동 고유성/동작·해부학/텍스트 없음/파일 정상 검수를 통과한 파일만 `assets/`에 넣는다.
5. 검수 미완료 사진은 게임 리소스로 병합하거나 G1/G2 완료로 기록하지 않는다.

**중요:** 문서 저장이 이미지 제작 완료를 의미하지 않는다. 생성 한계를 우회하기 위해 잘라낸 이미지를 사용하지 않는다.
