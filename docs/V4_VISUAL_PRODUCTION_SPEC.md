# LAST SIGNAL V4 — 실사 캐릭터 및 시네마틱 미디어 제작 명세

기준: 기존 main/index.html의 33개 SCENES, 4개 PERSONS, 5개 엔딩. 이 문서는 **설계 및 구현 계약**이며 이미지·영상 생성과 게임 코드 반영은 별도 작업이다.

## 목표
- 기존 선택지/서사/수치/엔딩 로직과 저장 데이터(version 3)를 유지한다.
- 33개 장면에 장면 ID별 서로 다른 실사 영화 스틸을 제공한다.
- 캐릭터 4명 각 얼굴 기준 1장, 전신 기준 1장, 인트로 전용 단체 컷 1장: 총 42장(33+8+1)을 1차 목표로 한다.
- 핵심 액션 8장면은 사전 제작된 3–5초 무음 MP4 또는 WebM을 제공한다. 모든 영상에는 대응 장면 정지컷 포스터가 있다.
- 플레이 중 이미지 생성/API 호출·유료 런타임 요구 없음. 오프라인으로 플레이 가능하게 한다.
- 대사·한글·UI는 DOM 텍스트로 출력. 이미지/영상 프레임 안에 자막, 대사, 로고, 워터마크를 생성하지 않는다.

## 캐릭터 바이블 (고정 필수)
- seoa / 윤서아 / 32세: 짧은 검은 머리, 날카로운 눈매, 현실적인 다부진 체격, 낡은 올리브/차콜 구조대 외투, 붉은 십자가 패치, 흠집 난 의료 가방. 시선은 주변과 사람의 상처를 먼저 확인. 위급할 때 짧고 단호한 말투. 재난 현장 구조·응급 처치가 행동 고유성.
- jiyu / 한지유 / 34세: 자연스러운 짙은 갈색 웨이브 중장발, 타원형 얼굴과 차분하고 계산적인 눈빛, 오래된 짙은 가죽 재킷, 정리된 무전기·정보 수첩. 상대방 반응을 읽는 제스처, 반쯤 드러나는 미소. 정보 수집·흥정·라디오 분석이 행동 고유성.
- soyeon / 박소연 / 30세: 짧은 거친 흑갈색 머리, 오른쪽 눈썹의 뚜렷한 작은 흉터, 체력 단련된 근육형 체격, 허리에 묶은 낡은 소방 재킷과 작업 장갑. 도끼/문/지지대 등 물리 구조물을 다루는 역동적인 포즈. 직설적이고 의리 있는 말투.
- nagyeong / 이나경 / 26세: 가벼운 앞머리의 단정한 검은 머리, 얇고 단정한 안경, 마른 체형, 실용적 연구복·오염된 실험복 레이어, 작은 연구 수첩과 장갑. 미세한 관찰과 시료 분석 제스처. 조심스럽지만 증거에 대해서는 단호한 말투.
- 얼굴·체형·헤어라인·상처 위치·의상 특징은 모든 장면에서 일관되게 유지한다. 인물 간 얼굴 바꾸기 금지. 기존 장면 원문에 등장하는 고유 소품·행동을 우선한다.
- 플레이어는 1인칭 시점의 무명 생존자이므로 임의의 플레이어 얼굴을 만들지 않는다.

## 시각 스타일 및 생성 계약
- 실제 한국 영화의 촬영 현장 사진 같은 photorealistic live-action movie still. 현실적인 35/50mm 광학, 자연광과 현장 조명, 입체감 있는 피부 질감과 의상 마모, 습기·먼지·땀 흔적.
- 장면 이미지: 16:9, 권장 1536x864 이상 원본에서 WebP 파생. 인물 도감 얼굴 기준: 3:4, 전신 기준: 2:3. 별도 인트로 표지: 16:9.
- 금지: 애니메이션/일러스트풍, 동일인 얼굴로 보이는 인물들, 과한 미용 보정, 인공적인 패션 화보 자세, 얼굴/팔다리/손가락 왜곡, 이미지 내 텍스트/말풍선/자막/로고/워터마크, 같은 그림 단순 재크롭으로 다른 장면 대체.
- 8개의 캐릭터 기준 사진을 인물당 개별 생성한 뒤 얼굴과 의상 기준을 확정한다. 이후 장면 생성 시 해당 인물의 동일 기준 사진을 레퍼런스로 사용한다. 여러 인물이 나오면 각 인물 레퍼런스를 함께 제공하고 얼굴 위치를 지정한다.
- 모든 이미지 파일은 장면 ID와 대응. 자세한 쇼트 설명과 미디어 경로는 docs/v4-scene-manifest.json 참조.

## 미디어 렌더러 계약
1. 장면 소스 조회는 장면의 image 키(17개) 대신 scene ID(p0, p1, ..., e_dead)를 사용한다.
2. 주 장면은 실사컷 자체가 인물을 포함한다. 현재 sceneHTML()의 장면 위 초상화 charportrait 강제 오버레이를 제거한다. 인물 도감에서는 각자의 얼굴 기준 이미지를 사용한다.
3. 영상이 있으면 poster→muted playsinline 짧은 액션(최초 1회)→포스터로 복귀. 자동 반복하지 않는다. 실패·저전력·데이터 절약·prefers-reduced-motion 상태에서는 정지컷만 사용한다.
4. 현재 장면만 영상 재생 대상으로 지정. 이전 대화 타임라인에 있는 영상은 포스터로 표시하고 모두 정지시킨다. 페이지 숨김/스크롤 이탈 시 일시 정지·해제.
5. 고유 경로의 이미지를 lazy-load하고 다음 진입 가능 장면만 선별적으로 prefetch. 최초 플레이 화면용 리소스는 eager. width/height 또는 aspect-ratio 명시로 이미지 로딩 시 스크롤 점프를 막는다.
6. 기존 followLatestScene()/scrollToLatest()/선택지 스크롤 유지. 이미지 로드 후 마지막 장면이 보이되 사용자가 수동 스크롤 중인 경우 강제 이동 금지.
7. import/export, localStorage KEY, state.version=3, SCENES 선택지·수치 분기 규칙은 변경하지 않는다. V4 리소스 교체만으로 저장이 무효화되지 않아야 한다.
8. 실행 링크와 배포는 기존 GitHub Pages 경로를 그대로 유지한다.

## 애니메이션 우선 장면 (8개)
- p3: 윤서아가 손전등을 겨누다 천천히 낮추며 상처를 확인.
- c1a: 윤서아가 약국 구급상자를 집어 들며 창밖 소리에 반응.
- c2a: 한지유가 철문 앞에서 무전기를 끄고 상대를 살핌.
- c3b: 이나경이 연구 수첩을 들고 샘플이나 상처를 분석.

움직임은 3–5초의 작고 맥락 맞는 현실적인 행동. 과장된 카메라 회전, 얼굴 모핑, 불필요한 폭발 효과 금지.

## 단계별 납품 게이트
G0 — 소스/스토리와 미디어 계약 확정: 33개 scene ID가 매니페스트에 정확히 한 번씩 존재하고 원본 분기가 유지되는지 검증.
G1 — 기준 이미지 8장 승인: 네 명의 얼굴을 나란히 비교해 실루엣·연령·특징 중복 제거. 단계 미통과 시 장면 사진을 양산하지 않는다.
G2 — 최초 4개 장면(p0–p3) 실사 적용 + 자동 스크롤/선택지/로딩 검증. 비주얼 방향 확인 후 확장.
G3 — 33개 장면 사진 + 인트로 1장 완료. 각 scene ID마다 실질적으로 다른 샷·상황·시점. 파일 중복 및 내러티브 충돌 0건.
G4 — 모션 8개 및 모바일 안전 재생 구현. 재생 실패/감속 설정 시 즉시 정지컷 폴백.
G5 — 전체 33개 장면, 5개 엔딩, 선택지·신뢰도·저장 불러오기, 새로고침, 뒤로 가기, 최신 자동 스크롤, 오프라인 재접속, Android Chrome에서 검증. 배포 후 직접 링크 실행 확인.

## 테스트/검수
- 장면: manifest sceneIds와 Object.keys(SCENES) 집합 일치, 파일 존재, 해시 중복 0.
- 인물: 사진 검수에서 머리/눈썹 상처/의상/얼굴 형태가 기준과 일치하고 팔다리 왜곡 없음.
- 서사: 실제 scene.text에서 벗어난 동작/장소 없음; 장면 내 자막 텍스트 없음.
- 성능: 모바일에서 전 장면 이미지 동시 디코딩 금지; 동영상 동시 재생 최대 1개; 이미지 최적화 및 지연 로딩.
- 호환: V3 저장 파일을 V4에서도 계속 불러올 수 있고 현재 장면과 신뢰도가 유지됨.
- 배포: main 업데이트 후 Pages 성공 확인, 실제 브라우저 33개 장면과 기본/엔딩 플로우 검사.

마스터 원칙: **같은 배우, 다른 상황, 다른 행동.** 단순히 동일 초상에 Ken Burns 확대 효과를 넣는 것은 실제 행동 모션으로 간주하지 않는다.
