# LAST SIGNAL — 실사 영상형 인터랙티브 드라마 전환 계약

2026-11-02. **기존 6막·14챕터·79장면·5결말, 분기·저장·확정된 등장인물 외형은 유지**한다. 기능 개발만으로 실사 촬영/영상 생성이 완료됐다고 말하지 않는다.

## 플레이 화면
- 게임은 **한 순간에 하나의 16:9 장면**만 보여준다. 콜라주, 분할화면, 합성 대시보드, 다른 장면의 이미지 재활용은 금지.
- '영화 모드'는 기본 켜짐이며 플레이어가 토글해 브라우저에 로컬 저장할 수 있다. 집중 모드는 상단 스탯/경로 도표만 숨기고 본문·선택지·사건 기록 접근을 지우지 않는다.
- 장면 진입 시 승인된 **해당 장면만의 영상**이 있는 경우, 무음 자동 재생 → 영상 종료 시 같은 장면의 승인된 사진 → 플레이어의 선택으로 다음 장면. 실제 영상이 없으면 *실사 제작 대기* 및 각 장면의 구별되는 임시 분위기 연출만 표시한다.
- 영상의 오디오는 사용자가 '소리 켜기'를 직접 탭해야 한다. '다시 보기', '영상 건너뛰기' 제공. 다음 장면, 탭 숨김, 화면 밖 이동에서는 이전 영상 재생을 중단한다.
- 모바일 데이터 절약 모드와 접근성 동작 감소 설정에서는 영상 자동 재생 없이 **같은 장면 사진**으로 대체한다. 한 번에 영상 1개만 유지한다.

## 첫 제작 단위 — P0~P3 (장면당 독립 3~5초 영상)
각 클립은 동일 장면으로 검수받은 고유 WebP 스틸이 먼저 있어야 한다. 각각 16:9 영화적 카메라 구도, 실생활의 자연스러운 피사체 움직임, 화면 속 자동 생성 문자 금지.

| ID | 영상 동작 | 금지할 오류 |
| --- | --- | --- |
| P0 | 야간 편집실. 빗방울이 창에서 흘러내리고 모니터 추상 파형이 움직이는 중거리 숏. 얼굴 없음 | 항구, 기자 얼굴, 마이크, 인터뷰 사진, 대시보드 |
| P1 | 수정원고를 펼친 손이 펜을 내려놓는 50mm 작업대 근접 숏. P0와 완전히 다른 렌즈/구도 | 글자가 읽히는 가짜 기사, P0 확대/크롭 |
| P2 | 비 오는 옥상. 난간에 빗방울이 떨어지고 먼 건물의 붉은 항공등이 깜박이는 와이드 숏 | 고정 캐릭터 얼굴 임의 생성, 홍보성 합성 |
| P3 | 가상 항구의 새벽 추모 공간. 약한 바람에 국화 꽃잎이 흔들리고 젖은 바닥에 반사되는 빛 | 실제 참사 사진, 실제 피해자 재현, 가짜 이름표 |

이후 윤서아·박소연·한지유·이나경이 등장하는 영상은 **기존 승인된 얼굴을 기준**으로만 제작한다. 승인 얼굴과 다르면 장면 불합격이다.

## 에셋 출고 절차
1. 장면에 맞는 개별 WebP 1장 생성 → 실제 사람·환경의 자연스러운 사진인가, 정확한 장면인가, 콜라주가 아닌가 **육안 검수**.
2. 실제 3~5초 동작 영상 1개 제작. 사진에 단순 확대·좌우 이동을 붙인 것을 '배우가 움직이는 영상'으로 인정하지 않는다.
3. 해시와 바이너리를 검증하고 `reboot/media/scenes/<scene-id>.webp`와 `reboot/media/motion/<scene-id>.webm`에 넣는다. `manifest.js`에 `approved:true`, `motionApproved:true`, 두 파일의 정확한 SHA-256을 기록한다.
4. `node scripts/verify-reboot-cinema-assets.mjs --strict-prologue`, 전체 테스트, GitHub Pages 모바일 검수를 통과해야 **영상 완료** 표기.
5. 사용자 추가 과금 요청 전에는 유료 클라우드 영상 생성을 호출하지 않는다. 런타임 동영상 재생은 정적 파일이며 AI API 호출·외부 계정이 필요 없다.

**현재 실사 영상 출고: 0개.** 영상 플레이어 코드, 임시 배경, 실사 제작 자체는 서로 별도 마일스톤으로 추적한다.
